# Java задание — Автомобили

Учебное приложение для работы с коллекцией автомобилей на Java 17+.

Можно добавлять автомобили вручную или загружать из CSV, отбирать по мощности
и сортировать по году выпуска.

Загрузка из CSV добавляет автомобили к имеющимся. Формат: UTF-8 без заголовка,
одна запись `модель;мощность;год` на строку. Пример — `examples/cars.csv`.
Кавычки и `;` внутри модели не поддерживаются.

Для сборки и запуска тестов нужны JDK 17+ и Maven 3.9+.
Из корня проекта:

```sh
mvn verify
```
